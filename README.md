<br/>

<img src ="https://drive.google.com/file/d/12jAiUAvA7lcpdjR8tAMdEg7IXz8RRYw8/view?usp=sharing"/>

<br/>

해당 프로젝트는 **국가별로 효과적으로 메달 집계하기 위하여** 를 위하여 기획되었다. 

각각의 입력창에 필요한 데이터를 입력하고 **입력하기 버튼**을 누르면 해당하는 **메달 현황표** 가 보이고,
현황표에서 내용을 삭제하고자 빨간 **삭제 버튼**을 누르면  **해당하는 메달 현황** 만 삭제된다. 

이미 있는 국가의 메달 현황을 수정하고 싶다면, 입력 창에서 메달 정보만 수정하여 **업데이트 버튼**을 눌러 **집계 정보 갱신**을 할 수 있다.

# 프로젝트의 한계 

<br/>

+ 아직 들어온 집계 현황이 없어도 집계 현황표 **테이블 head** 부분이 드러난다. 집계 현황이 없을 시 안내 문구를 확인할 수 없다.

+ 시간 상의 문제로 CRUD 기능 중 **Update**, 정보 갱신 기능이 완료되지 않았다.

+ **jax 파일 내부 컴포넌트 모듈화**가 되어 있지 않다.
